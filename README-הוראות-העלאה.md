# A Bit More — אתר עצמאי (הוראות העלאה ל-Vercel)

התיקייה הזו היא עותק מלא ועצמאי של האתר. הוא אינו תלוי יותר בשום מערכת חיצונית: אין מסד נתונים, אין שרת מיוחד, והוא נבנה ועובד לבד. כל הפניות ליצירת קשר עוברות לוואטסאפ.

---

## אפשרות א' — העלאה ל-Vercel דרך הדפדפן (הדרך הקלה, מומלצת)

1. היכנסו ל-https://vercel.com והירשמו בחינם (אפשר עם חשבון Google / GitHub / אימייל).
2. לחצו על **Add New…** → **Project**.
3. בחרו באפשרות להעלות קבצים (Deploy / Upload). אם Vercel מבקש מאגר GitHub, ראו אפשרות ב' למטה.
4. גררו את **כל התיקייה הזו** (או את קובץ ה-ZIP) לחלון ההעלאה.
   - חשוב: אל תעלו את תיקיית `node_modules` אם היא קיימת — Vercel מתקין את התלויות בעצמו.
5. Vercel יזהה שזה פרויקט Next.js ויגדיר הכל אוטומטית. לחצו **Deploy**.
6. אחרי דקה-שתיים האתר יהיה באוויר בכתובת זמנית כמו `your-project.vercel.app`.

---

## אפשרות ב' — דרך GitHub (מומלץ אם רוצים לעדכן בקלות בעתיד)

1. פתחו מאגר (repository) חדש ב-GitHub והעלו אליו את כל הקבצים מהתיקייה הזו.
2. ב-Vercel: **Add New… → Project → Import** ובחרו את המאגר.
3. לחצו **Deploy**. מעכשיו, כל שינוי שתעלו ל-GitHub יתעדכן באתר אוטומטית.

---

## חיבור דומיין משלכם (אופציונלי)

1. ב-Vercel, בתוך הפרויקט: **Settings → Domains → Add**.
2. הקלידו את הדומיין שלכם (למשל `www.abitmore.com`) ועקבו אחרי ההנחיות.
3. Vercel ייתן לכם רשומות DNS להזין אצל ספק הדומיין שלכם. אחרי האימות (כמה דקות עד כמה שעות) האתר יוצג בדומיין שלכם.

---

## Google Analytics (אופציונלי)

האתר מוכן לאנליטיקס אבל כרגע מושבת (יש מזהה זמני).
כדי להפעיל: ב-Vercel → **Settings → Environment Variables** הוסיפו משתנה:

- שם: `NEXT_PUBLIC_GA_ID`
- ערך: המזהה האמיתי שלכם (בפורמט `G-XXXXXXXXXX`)

ואז לחצו **Redeploy**. (בקובץ `.env.example` יש דוגמה.)

---

## הרצה מקומית על המחשב (למי שרוצה לבדוק לפני)

צריך Node.js מותקן. בתוך התיקייה:

```
npm install
npm run dev
```

ואז לפתוח בדפדפן את `http://localhost:3000`.
לבנייה לפרודקשן: `npm run build` ואז `npm run start`.

- כל התמונות, הטקסטים (עברית ואנגלית) וההגדרות כבר בפנים.
